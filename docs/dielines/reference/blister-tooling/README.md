# Blister tooling formats

Log of PharmaCenter's blister machine tooling (change part) formats. One file
per format, named `<maker>-<machine>_<card size>_<cavities>_<cavity>_<drawing date>.pdf`.
Reference only -- these are not served by the site. A future Dielines blister
module will read its card sizes and cavity layouts from here.
